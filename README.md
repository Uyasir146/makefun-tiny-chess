The strongest chess engine that fits in 4,096 bytes of Python: iterative deepening alpha-beta over
its own move generator, quiescence on captures, MVV-LVA ordering and a tapered piece-square
evaluation, played through the competition's env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3.13 main.py
```
